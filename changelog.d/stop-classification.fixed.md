A launch that ended normally is `completed` whatever its answer says. A Claude Code answer that mentioned a rate limit, such as the summary of a task that added rate limiting to an API, was `rate_limited`: the route rested and the task ran again on the next hop. Only an error result's words can now make a launch `rate_limited`, `auth_failed` or `refused`. Codex reads a quota refusal or a refused credential only in the forms that it prints, such as `unexpected status 429 Too Many Requests` and `You've hit your usage limit`, so a failed launch whose stderr holds `line 429` in a traceback or a path such as `quota.py` no longer rests its route.

**Web packages.** The monitor's page is built from three npm packages that work in any
page or framework: `@contraagent/api` (types generated from `openapi.json`, a client, the
live feeds, a store), `@contraagent/elements` (generic web components: a data table,
charts, a layered graph, a mark matrix, a transcript, tiles, lanes, a JSON tree, markdown,
and the themes) and `@contraagent/ui` (`<ca-monitor>` and an element for each view, each
importable alone).

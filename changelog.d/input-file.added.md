`InputFile`, a file a task is given as a param by its path and the SHA-256 of its content, taken at the task call: a field of an agent task's params model or a parameter of a Python task (`InputFile(pending.path)` for a received text output, `InputFile("in/spec.md")` for a file on disk). The params hold `{"path", "sha256"}`, with a JSON Schema that tells the agent to read the file; the fingerprint holds both (journal `fingerprint_parts` `input_files`); a task whose file no longer has that content as it starts is refused (`invalid_input`); and a path outside the working directory and the run's `out/` raises `ValueError` at the call. A Python task is given it with an absolute path, and `read_text` and `read_bytes` check the content. `PythonTask.arguments` and `PythonTask.invoke` take `cwd=`, the directory a relative path is under. See "Large inputs" in `contraagent docs tasks`.

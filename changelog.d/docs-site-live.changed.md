**The documentation site shows every element live.** Each topic of `@contraagent/elements` and each view in `@contraagent/ui`'s "The views" draws its element, live, where the packages' files show a screenshot (`<ca-monitor>` reads an export of the demo run); a landing page presents contraagent and where to start; the sidebar groups the Python package, the web packages and the reference; the element reference is a page per package, readable on a phone. The npm tarballs of `@contraagent/ui` and `@contraagent/elements` hold no images.

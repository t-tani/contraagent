On Windows, paths are written with `/` as on Linux and macOS: the contract records' `path`, the errors a check reports (`out/<kind>/<unit>.json: ...`), the monitor's flow files and plugin files, the documentation's code titles, and what `contraagent run` and `contraagent check` print. A `changes` pattern or an `output_name` that starts at a root (`/`, `\` or a drive such as `C:`) is refused on every OS. An opencode `read` or `edit` pattern for a file on another drive stays absolute, and `contraagent hub --segments file:///C:/...` reads a Windows path.

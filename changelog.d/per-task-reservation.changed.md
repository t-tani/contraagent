A `PerTask(memory_mb=...)` claim capacity reserves a task's `memory_mb` from its start until it ends, instead of for its first 30 seconds. A task starts when the reserved `memory_mb` with its own is at most the free memory read while no `PerTask` task runs, and the free memory now is at least its `memory_mb`. A task that takes its memory late no longer lets the host start too many, and one that takes it early is no longer counted twice. `ClaimCapacity` has a new method, `ended()`, which the queue calls when a task that claims the name ends.

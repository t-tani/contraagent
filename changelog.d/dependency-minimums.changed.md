contraagent requires pydantic 2.11 or later, the first release that serializes a model by its field aliases (`serialize_by_alias`). With an earlier release, a loop's pass was written as `pass_` instead of `pass` in `plan.jsonl`, `flow_calls.jsonl` and the monitor's API. The `monitor` extra requires sse-starlette 3.0 or later, the first release that gives each event loop its own shutdown event. With an earlier release, a server that started after another one in the same process ended each of its event streams with an error.

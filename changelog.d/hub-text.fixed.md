One damaged record no longer stops a host's relay. The hub's Postgres store refused a batch that held a NUL, as a log line filled with zeros after a power loss does, and the relay then sent none of the host's later runs and tried the same batch again. A file name or a process argument that is not UTF-8 stopped the runs or the heartbeat in the same way. A hub now holds a NUL outside a transcript as SUB (U+001A), so a damaged line still reads as no row, and a byte that is not UTF-8 as its escape (`\udce9`). A contract's path that no file system has is a missing file. A run, a log or a document whose name is not UTF-8 is left out with a warning. The hub's database needs no migration, and an upgraded hub also takes the NUL that an older relay sends.

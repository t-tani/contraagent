**Monitor wording.** The monitor's English and Japanese text is shorter and uses one form for each kind of text. Each term has one definition everywhere: a retry, a correction and a model switch. The Trends page counts attempts and tasks as done, not passed, and names denied tool calls. A run that finished with failed or not-started tasks gives their count, and a cause names the input problem that the data records instead of "missing or failed checks". Tasks done after retrying appear under a heading of their own beside the problems, and a few tooltips that only repeated their label are gone.

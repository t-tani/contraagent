contraagent reads omp's `.omp/config.yml` and `.env` in the directory the launch runs in, as omp does, not in the directory the pipeline process was started in. A task call with its own working directory (`.options(cwd=)`) gets the account of the key in that directory's `.env`, and a `.env` there that would undo its credential's isolation refuses a task that requires traits before anything launches. The preflight probes each route in the run's working directory (`Pipeline(cwd=)`), and its line on omp's own model chain is that directory's. `Backend.bind_credential` and `Backend.account` take `cwd`, the directory the launch runs in; `RoutingPlan` and `RoutingPlan.build` take `cwd`, the run's working directory; `RoutingPlan.call_problems` and `AgentRunner.account_of` take the call's or the launch's `cwd`. A custom `Backend` that overrides `bind_credential` or `account` adds the `cwd` keyword.

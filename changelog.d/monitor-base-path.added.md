Monitor behind a reverse proxy: `contraagent monitor --base-path /monitor` and `contraagent hub --base-path /monitor` serve a page that names the base path in every URL it reads (`<ca-monitor base-url="/monitor">`, its script and icons), so a proxy that serves the monitor under `/monitor/` of a site and takes that path off passes the page, the API and the live feeds with no change to the HTML. The API documentation and the OpenAPI document's `servers` name it too, and a hub's `/login` redirects to it and sets its cookie for it. A value that is not a plain path ends the command with exit status 2. `create_app(base_path=)` and `serve(base_path=)` in `contraagent.monitor` take the same. The monitor topic (`contraagent docs monitor`) shows an nginx configuration and what a proxy needs for the live feeds and the `Host` check.

The memory of a `PerTask` claim capacity is the host's for every name. While no running task holds memory by a `PerTask` claim, one task starts whatever the memory, so that a run goes on; that exception was each name's own, so the first task of each name started over the memory: with two `PerTask` names, or with a pattern such as `mem:*` that gives each unit a name, the tasks took more memory than the host had. The starvation guard still keeps a place for a waiting task whose capacity the host sets

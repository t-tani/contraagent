Services: `Pipeline(services={name: service})` names the long-lived helper (a worker service, a database, a local server) that a claim name stands for. `Service` is a function of the name that returns a context manager. The first task that claims the name starts the service, every task that claims it shares it while it runs, as many at once as its claim capacity lets, and the run's end stops it, on an error and on Ctrl-C or SIGTERM too; `service_idle_s=` stops one that no task holds and starts it again for the next claim. A task reaches it by the address its start gives: `contraagent.service_address(name)` in a Python task, `CONTRAAGENT_SERVICE_<NAME>` in an agent task's environment. A start that raises fails the tasks that claim the name with stop `launch_failed`. `services.jsonl` records each start and stop, the monitor shows them under "Services" (`Plan.services`, `ServiceSpan`), and `contraagent check` names a service that no task claims.

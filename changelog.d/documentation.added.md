**Documentation.** Each package installs its documentation with it: `contraagent docs`
prints the index, `contraagent docs <topic>` a topic (a tutorial, a guide, the concepts,
tasks, plugins, contracts, routing, testing, the monitor, the hub and compatibility), and
`contraagent docs --pointer` a block that points a project's coding agent at them. The
examples under `docs/examples/` (a demo pipeline, generator flows, an annotated reference
config, a hub deployment) run in the test suite.

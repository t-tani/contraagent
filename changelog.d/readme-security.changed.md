**The README's section for security engineers, with diagrams.** It draws what a task's coding agent is given and what is kept out, how a safeguard refusal moves one task along a failover chain across coding agents, and how a credential reaches a launch, and it puts the controls and records in one table. The chain is a tested example, `examples/security/pipeline.toml`: Claude Code on `claude-opus-5-5`, then Codex CLI on `gpt-6.1-sol`, then opencode on `opencode-go/deepseek-v4.1-flash`.

A run ends when flow code goes on after the driver cancels a flow call that waits for what nothing will answer, and waits again: a retry loop that catches every exception catches that cancellation too. The run went on until its deadline, or for ever without one, and cancelled the flow call at every pass of the queue. The flow call is now cancelled once and recorded `closed` when it still waits; code that creates a task after the cancellation gets the task's answer as before

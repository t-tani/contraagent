`agent = "agy"` runs the Antigravity CLI (`agy -p --output-format stream-json`, checked against agy 1.5.9). A task's plugin reaches it in a directory of the launch's own, added to agy's workspace: a copy of its skills, its hooks (`agy/hooks.json`, rendered from `hooks.toml` and run through `contraagent plugin hook --agent agy`) and its MCP servers. A `stop` hook continues the session, a `pre_tool` hook denies a call, and a `post_tool` hook's words reach the model before its next response. The role's file is attached to the prompt, and a light launch runs as an agent of agy's own with no tools. A launch runs in agy's `auto` mode (commands in its terminal sandbox, with the network unless the task denies `WebFetch`, and agy's own review of one that asks to leave it); a launch that agy ends on a tool call nobody could approve ends `denied`. `max_turns` and `context_budget` are enforced by contraagent; agy reports no cost, so `max_budget_usd` is not. `disallowed_tools` become deny rules of agy's permissions. A model id names its reasoning level (`gemini-3.8-flash-high`) or takes `effort` (`gemini-3.8-flash`). The credentials are `ambient`, a `subscription` of provider `google` (agy's Google login) and an `api_key` of provider `google` (a Gemini API key). For a Google login, the plan's weekly and 5-hour usage is read before a launch (`agy -p /usage`), so a credential rests on its quota. Outside a light launch agy has no switch for the project's and the user's own rules, skills, hooks and MCP servers, and a launch reads them. `contraagent.backends.AgyBackend` is its backend, and `agy` a stream format of the monitor.

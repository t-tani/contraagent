**The documentation site's landing page replays a run.** The first screen states what contraagent does, with the install command (and a copy button) and the five coding agents that run the same tasks. As the reader scrolls, it stays in place and recedes while the replay's window rises over it and settles flat. In the replay, the demo pipeline's flow code, quoted from the tested example, appears line by line. Then its run on the demo agent plays again from its records in `<ca-pipeline-graph>`, `<ca-kpis>` and `<ca-transcript>`. Each line of code is lit while the tasks it created run, and the run's corrections, model switch and second loop pass are listed below it in words. The replay starts when it is settled on screen and can be paused. With reduced motion, the page has no scroll effects and shows the finished run at once. Below the replay: the path from install to the monitor, whose line fills as the reader scrolls, the runner's capabilities, and the entry points to the Python package, the web packages and the reference, each rising into place as it comes into view. The transcript in the replay shows new lines a few times a second, and fades once when it changes to another task.

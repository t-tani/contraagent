**The documentation site's landing page replays a run.** The demo pipeline's flow code, quoted from the tested example, appears line by line; then its run on the demo agent plays again from its records in `<ca-pipeline-graph>`, `<ca-kpis>` and `<ca-transcript>`, each line of code lit while tasks it created run, with the run's corrections, model switch and second loop pass in words below it. It starts when on screen, can be paused, and shows the finished run at once with reduced motion. Below it: the path from install to the monitor, and the entry points to the Python package, the web packages and the reference.

A record that only the monitor reads no longer fails a task or a run when it cannot be written. A transcript on a full disk stopped the running coding agent, and the retry launched it again; the agent now works to its end. A plan row, a flow call or a deferral that could not be written, or a running task's marker that could not be removed, ended the flow or the run. Each is now a warning line and a count in `RunReport.summary["record_failures"]`, as are the contract records, the definitions and the service events, which were not counted. A task whose running marker cannot be written does not start and ends with stop `launch_failed`: a resume reads the marker to tell an attempt that the run's end cut from one that finished.
